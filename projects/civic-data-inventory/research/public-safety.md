# Public Safety Data Inventory — Portland / Multnomah County / Oregon

## Overview

This inventory catalogs publicly accessible criminal-justice and public-safety data sources spanning the Portland Police Bureau (PPB), Bureau of Emergency Communications (BOEC/911), Portland Fire & Rescue (PF&R), Portland Street Response, Multnomah County Sheriff's Office (MCSO) jail data, the Multnomah County District Attorney (MCDA), the Multnomah County Local Public Safety Coordinating Council (LPSCC), Oregon's court system (OJD/OECI/OJCIN), Oregon State Police (OSP) CJIS/UCR, the Oregon Criminal Justice Commission (CJC), and the Oregon Department of Corrections (DOC).

**37 distinct sources** are documented below across three jurisdiction tiers (city, county, state), plus several third-party/community mirrors noted for completeness. Portland/PPB has the richest machine-readable, dashboard-driven ecosystem of any local agency in the region (part of the national Police Data Initiative). County-level jail and prosecution data is dashboard-rich but weaker on bulk download/API access. State-level data (OSP UCR/NIBRS, CJC, DOC, courts) is strong on aggregate statistics but the single richest record source — individual court case records via OJCIN — sits behind a paid subscription wall, which is the most significant access barrier identified in this domain.

**Research method note:** Web search was used extensively (16 distinct queries before the session's search budget was exhausted) and returned substantive, current results. However, live URL verification via WebFetch/curl was **not possible** in this environment — every outbound fetch attempt (including to control domains like `example.com` and `anthropic.com`) returned HTTP 403 at the network gateway level, indicating a session-wide outbound network restriction rather than a problem with any specific target site. All URLs below are as returned by search engine indexing and should be spot-checked before being embedded in a production visualization. Details are in "Notes & Caveats."

## Standouts

**Best for maps:**
- **PortlandMaps Crime layer (ArcGIS REST MapServer)** — the only source in this inventory offering a *live, queryable, point/block-level GIS API* (GeoJSON/Shapefile export) for crime incidents. This should be the backbone of any Portland crime map rather than scraping the Tableau dashboards.
- **PPB Shooting Incident Statistics dashboard** — purpose-built neighborhood-level graduated point map; strong direct fit for a gun-violence choropleth or point-density map.
- **City of Portland Geospatial Open Data Portal** (`gis-pdx.opendata.arcgis.com`) — broader ArcGIS Hub with downloadable layers in multiple GIS formats; worth a full separate crawl to catalog non-crime layers (council districts, neighborhood boundaries) needed to join with the crime data by geography.

**Best for time series:**
- **PPB Monthly Reported Crime Statistics** — multi-year, block-to-neighborhood granularity, monthly cadence, downloadable per-year CSVs — the strongest long-run city time series in the inventory.
- **Oregon DOC AIC Population Profiles + Corrections Population Forecast** — near-weekly snapshots plus a 10-year forward-looking forecast; combined, these support both historical and projected prison-population time series statewide.
- **MCDA Prosecutorial Performance Indicators** — quarterly, 32-metric panel that, combined over multiple quarters, forms a strong prosecutorial-pipeline time series (referrals → charges → dispositions).

**Best for cross-jurisdiction comparison:**
- **Oregon STOP Program (CJC/HB 2355)** — the standout cross-jurisdiction dataset in this domain: agency-level, exportable (CSV/XML), and covers **every** Oregon law-enforcement agency (PPB, MCSO, OSP, and all municipal departments) on the same schema (race/gender/age of stopped person, stop reason, search outcome). This is a better machine-readable source for stop-data analysis than PPB's own PDF-only Stops Data Collection Reports, and it's the only source that lets a visualization compare PPB against, e.g., Gresham PD or OSP patrol on stop disparities.
- **OSP Uniform Crime Reporting / Oregon-NIBRS** — the only apples-to-apples crime-count comparison across all ~236 Oregon agencies using a common offense taxonomy (Group A/B). Necessary if the visualization wants to contextualize Portland's crime trend against statewide or peer-city trends.
- **CJC Equity Dashboard** — explicitly built for demographic-disparity analysis across the criminal justice system; a natural cross-reference layer for any map/time-series built from the arrest, stop, or incarceration datasets above.

**Notable access-model contrast worth highlighting in the visualization's methodology notes:** PPB (city) publishes rich self-service dashboards and CSVs for free; MCSO (county) publishes only monthly PDF summary reports plus a non-bulk-exportable current-roster lookup; and OJD (state) locks the single richest record source — full case-level docket data — behind a paid subscription (OJCIN). This is a genuine three-tier access gradient across the same regional criminal-justice pipeline and could itself be a compelling "meta" visualization (e.g., an access-tier map layered over the jurisdictional map).

## Notes & Caveats

1. **URL verification was not possible in this research pass.** All WebFetch and direct `curl` attempts to external domains returned HTTP 403 at the network gateway/proxy level in this sandboxed environment — including to control/test domains (`example.com`, `www.google.com`, `www.anthropic.com`), confirming this is a session-wide outbound network restriction and not a site-specific block. The `$HTTPS_PROXY/__agentproxy/status` diagnostic showed a running log of `connect_rejected` (gateway 403) entries for essentially every attempted host. **Recommendation: before this inventory is used to build live data connectors, someone with working network access should spot-check each URL, particularly the ones flagged below as unconfirmed.**
2. **Search budget was exhausted before all planned queries completed.** 16 WebSearch calls were made (exceeding the 12-call minimum) before the session's search allotment (200 calls, shared across whatever else is running in this environment) was used up. Four planned follow-up queries — on PPB's Business Districts Crime Summary/Stolen Vehicle Statistics update cadence, PPB's arrest-statistics demographic breakdown detail, the `moto.data.socrata.com` PPB mirror's provenance, and MCSO's monthly report historical archive depth — could not be run. The rows above for those items are marked with lower confidence or "unconfirmed" where the detail could not be independently verified.
3. **OJCIN Online pricing** could not be confirmed with a specific dollar figure in this pass. Historically OJCIN has billed via account registration plus connect-time or subscription charges; the current fee schedule should be obtained directly from OJD Information Services (referenced at `courts.oregon.gov/services/online/pages/ojcin.aspx`) before any budget assumption is made for this project.
4. **DSS-Justice (Decision Support System-Justice)**, the cross-agency Multnomah County data warehouse referenced by LPSCC, is explicitly **not** independently public — it's an internal system whose outputs the public only sees via downstream LPSCC/MCDA/DCJ published reports. It's listed here for completeness/context but should not be treated as an accessible data source.
5. **PII handling:** MCSO's "PAID" inmate lookup and the DOC offender search (`docpub.state.or.us`) are individual-record lookup tools containing names and case-identifying information.

## Implementation Steps (single file: `OverviewView.tsx`)

### Step 1: Add a "Key Concepts" glossary section after the hero

New section between Hero and Governance Challenge. Renders as a compact 2×3 grid of definition cards. Each card has:
- **Term** in bold white + `<C>` monospace
- **Expansion** (e.g., "Policy Enforcement Point")
- **One-line plain-English definition**

Terms to define:
| Term | Expansion | Definition |
|------|-----------|------------|
| `PDP` | Policy Decision Point | Where access rules are stored — the single source of truth |
| `PEP` | Policy Enforcement Point | Where access rules are evaluated at query time (Snowflake, S3, Bedrock) |
| `RAP` | Row Access Policy | Snowflake's native mechanism for filtering rows based on user identity |
| `CTAS` | CREATE TABLE AS SELECT | SQL operation that materializes a query result — silently strips RAPs |
| `ENTITLEMENTS` | Entitlements Table | The mapping matrix: who can see what, populated by Okta + Salesforce |
| `RLS` | Row-Level Security | Restricting which rows a user can see based on their identity attributes |

Style: each card is a small bordered box with the `<C>` term prominent, expansion text below, and definition as gray text. Use `colorStyles` — PDP/PEP in emerald, RAP in blue, CTAS in red, ENTITLEMENTS in red, RLS in amber.

## Context

**Current state:** Single 1175-line `App.tsx` with 8 static sections. Shared primitives: `FlowDiagram`, `StackDiagram`, `PipelineDiagram`, `CalloutBox`, `InfoCard`, `DataTable`, `SectionHeader`, `SidebarItem`, `colorStyles`. Dependencies: React 18 + Tailwind + lucide-react + tailwindcss-animate. No additional libraries needed.

**Target:** Each of the 5 content sections gets a full interactive simulation inspired by the eval frontend patterns — clickable node graphs, step-through walkthroughs with animated data flow, interactive query playground, and sub-tab navigation. App gets split into separate component files to enable parallel subagent work.

**Key design patterns to apply:**
- **Step sidebar + detail panel** (eval frontend pattern): numbered steps on left, expanded detail on right with contextual content
- **Clickable node graph**: diagram nodes become interactive — click to highlight, show detail panel, animate connections
- **Sub-tab navigation**: sections with multiple conceptual areas get horizontal tab bar within the section
- **Animated data flow**: CSS transitions + tailwindcss-animate for step progression, node highlighting, data flowing through pipelines
- **Interactive playground**: toggle controls (dropdowns, switches) that change visible output in real-time

### Phase 1: Exec Summary — Interactive vulnerability chain + animated PDP/PEP
- **Clickable vulnerability chain**: FlowDiagram nodes become clickable. Clicking a node (e.g., "CTAS / Materialize") highlights it with a glow ring + expands a detail panel below showing the corresponding InfoCard content with animated slide-in. Unselected nodes dim.
- **Animated PDP/PEP architecture**: The 3 PEP boxes (Snowflake, AWS S3, Bedrock) become clickable. Clicking one shows an animated "data flow" line from PDP → selected PEP, with a detail callout explaining that platform's enforcement. Add pulsing dot animation on the connecting arrow.
- **Document roadmap**: Chips become clickable — click one and it navigates to that section tab.

### Phase 2: Developer Experience — Step-through SDLC simulation
- **Layout**: Left sidebar with 5 numbered steps (Develop → Ask Cortex → Promote → Gate → Live), right panel shows expanded detail for the active step.
- **Active step**: Highlighted with colored border + glow. Clicking a step transitions the right panel with slide animation.
- **Right panel content per step**:
  1. **Develop** — Shows sandbox schema mockup with CREATE TABLE statement, animated typing effect
  2. **Ask Cortex** — Simulated Copilot chat bubble: user asks "publish to BI", Copilot responds with grain analysis + schema recommendation
  3. **Promote** — Animated PipelineDiagram showing dbt post-hook firing, tag inheritance cascade
  4. **Gate** — Split view: dbt test output (pass/fail badges) + RAP null guard check
  5. **Live** — BI dashboard mockup with row-level filtering applied, showing ENTITLEMENTS-filtered rows
- **Auto-play mode**: Optional "Play" button that auto-advances through steps with 3-second delay.
- **AI-Assisted Promotion sub-section**: FlowDiagram nodes (Intent → Analysis → DDL) become clickable with expanded detail, same as Exec Summary pattern.

### Phase 3: Enforcement — Interactive pipeline simulation
- **ENTITLEMENTS promotion pipeline**: Each gate node is clickable. Clicking a gate shows:
  - What it checks (schema validation, dedup, delta threshold)
  - Simulated pass/fail scenario toggle — user can switch between "Valid Record" and "Malformed Record" to see the gate accept/reject with animated checkmark/X
  - Data flow animation: a colored dot travels from source → through gates → to sink, pausing at the active gate
- **Defense-in-depth stack**: StackDiagram layers become clickable — clicking a layer expands an inline detail panel showing what happens when that layer fails (and why the system still holds).
- **GLOBAL alert simulation**: A toggle that simulates inserting a GLOBAL access record — shows the alert chain firing in real-time with animated notifications.

### Phase 4: Policy Logic — Interactive RAP query playground
- **Identity selector**: Dropdown with mock users (Alice: Region=West, Bob: Opportunity=OPP-123, Charlie: GLOBAL, Eve: No entitlements)
- **Live query trace**: The SQL block becomes interactive — as the user selects an identity, the relevant CASE branch highlights with a colored glow, and a result panel below shows "Rows returned: 47" or "Access DENIED — null guard triggered"
- **Row-level visualization**: A small mock data table (5-6 rows) that filters in real-time based on the selected identity. Denied rows animate with strikethrough + red tint.
- **Memoizable function explainer**: Click-to-expand panel showing cache hit/miss simulation.

### Phase 5: Tag Taxonomy + Schema Design — Interactive tag propagation
- **Tag cascade visualizer**: Click a tag (DATA_DOMAIN, DATA_SENSITIVITY, etc.) → see an animated tree showing which schemas inherit it, which RAP fires, and what masking applies.
- **Schema selector**: Click a schema (SALES_GRANULAR, SALES_BY_REGION, SALES_GLOBAL) → detail panel shows the security grain columns, the active RAP, and a mini data preview with the access control applied.
- **PII interaction rule**: Interactive toggle showing "What if this column is BOTH a PII target AND a RAP filter?" → shows the conflict + the separation rule enforcing.
- **PDP/PEP pattern** (currently in SchemaView): Same interactive pattern as Exec Summary's PDP/PEP diagram.

### Phase 6: Polish — OpsView + global UX improvements
- **Phase timeline**: Interactive phase 1/phase 2 cards with expand/collapse and progress indicators.
- **Federated governance RACI**: Hover/click rows to see expanded responsibilities.
- **Global**: Add keyboard navigation (arrow keys to step through simulations), smooth scroll when navigating from roadmap chips, loading skeleton for section transitions.

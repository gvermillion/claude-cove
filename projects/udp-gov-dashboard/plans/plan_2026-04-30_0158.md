## Context

The current Tag Resolution Playground has 4 independent pill selectors (domain × sensitivity × grain × piiPolicy = 144 combos). Most combos are meaningless or duplicate. Replace with a single curated dropdown of ~7 known cases, each pre-selecting all 4 tag values. The resolution panel and masking playground remain unchanged — they still consume `resolveTagSelection(tagSelection)`.

**Key finding:** Only `HR__INDIVIDUAL` has PII columns (EMAIL, FULL_NAME, SSN_LAST4). Only RESTRICTED sensitivity activates masking. So the interesting masking scenarios all route through HR + OPP_ID + RESTRICTED.

### Step 2 — Replace 4 individual state variables with a single scenario index

**Remove:**
- `selectedDomain`, `selectedSensitivity`, `selectedGrain`, `selectedPii` (4 `useState` calls)
- `tagSetters`, `tagSelections` records
- `tagSelection` manual object construction

**Replace with:**
```ts
const [selectedScenario, setSelectedScenario] = useState(0);
const tagSelection = tagScenarios[selectedScenario].tags;
const resolved = resolveTagSelection(tagSelection);
```

Keep `selectedPii` derivable: `const selectedPii = tagSelection.piiPolicy;` — needed by masking playground's CASE branch highlighting and the IIFE.

### Step 3 — Replace left-column tag selectors with scenario dropdown

Remove the `tagMeta.map()` 4-selector grid. Replace with a stacked list of scenario buttons (same visual pattern as the Write Path target selector — stacked buttons with label + description):

```tsx

  <div className="flex flex-col gap-1.5">
```

Below the scenario list, show the resolved tag values as read-only chips (so users still see what tags were set):
